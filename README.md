# LabourNomics-MY
LabourNomics MY is a brand new platform designed to provide insights into the Malaysian economic landscape based on a study titled "Dynamic Interactions Between Unemployment Rate and Malaysia's Gross Domestic Product (GDP): Forecasting Using Vector Autoregression (VAR) Approach."

## Project Dashboard
![LabourNomics MY Dashboard](LaborNomics%20MY%20Dashboard.jpg)

## Key Features

- Time Series Analysis
- Unemployment Rate
- Gross Domestic Product (GDP)
- Vector Autoregression (VAR)

## Statistical Tool

- R Shiny in R
